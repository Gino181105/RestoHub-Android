# Imágenes gastronómicas reales incluidas

Las ilustraciones de productos fueron sustituidas por fotografías reales de platos peruanos para mejorar la presentación visual de RestoHub.

Las imágenes fueron recortadas y optimizadas a WebP para su uso como recursos Android locales.

## Créditos

- **Ceviche / Cebiche de corvina** — Picanteria karol — Wikimedia Commons — CC BY-SA 4.0.
- **Lomo saltado** — WikiHes — Wikimedia Commons — CC BY-SA 4.0.
- **Chicha morada** — young shanahan — Wikimedia Commons — CC BY 2.0.
- **Suspiro limeño** — Luisfranciscopm — Wikimedia Commons — CC BY-SA 4.0.
- **Ají de gallina** — Feralbt — Wikimedia Commons — CC BY-SA 3.0.

Se conservaron los nombres de recurso Android (`product_ceviche`, `product_lomo`, etc.) para que la base de datos local existente siga resolviendo las imágenes sin cambiar el código de productos.
