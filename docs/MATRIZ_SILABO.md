# Matriz de cumplimiento del sílabo

| Tema | Evidencia en RestoHub 5.0 |
|---|---|
| Kotlin | Variables, funciones, enums, null safety y data classes |
| POO | Clases, constructores, interfaces DAO, objetos y separación de responsabilidades |
| Corrutinas | `suspend`, `viewModelScope`, `Dispatchers`, Flow y StateFlow |
| Componentes Android | Button, TextView, EditText, CheckBox, RadioButton y Spinner |
| Intents explícitos | Login, formularios, ventas, pedidos y comprobantes |
| Intents implícitos | Compartir PDF y abrir ubicación |
| Cámara y permisos | Fotografías de producto y perfil con FileProvider |
| Fragments | Inicio, carta, carrito, pedidos, perfil, dashboards, usuarios y comprobantes |
| Material Design | Toolbar, Cards, TextInputLayout, Snackbar y diálogos |
| NavigationDrawer | Menú lateral adaptado al rol |
| BottomNavigation | Menús diferentes para cliente, recepción y administración |
| MVVM | ViewModel + Repository + DAO mediante una Factory |
| RecyclerView | Productos, carrito, pedidos, usuarios, comprobantes y detalles |
| Retrofit/JSON | Consulta remota de recetas y backend REST incluido |
| Glide | Recursos locales, URI de galería/cámara y URL |
| Room/SQLite | Seis tablas, claves foráneas, índices y transacciones |
| CRUD | Productos, usuarios, pedidos y comprobantes |
| SharedPreferences | Sesión y rol activo |
| Persistencia | Stock, carrito, pedidos, usuarios y comprobantes |
| Servicios REST | Productos, usuarios, pedidos, comprobantes y dashboard en Node.js |
| UX | Mensajes, estados vacíos, validación, navegación por rol y prevención de acciones inválidas |
