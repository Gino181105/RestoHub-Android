# Pruebas manuales de RestoHub 5.0

Antes de probar, desinstala una versión antigua o borra los datos de la aplicación.

## Autenticación

1. Ingresar como cliente.
2. Ingresar como recepcionista.
3. Ingresar como administrador.
4. Crear un nuevo cliente.
5. Recuperar una contraseña.
6. Probar credenciales incorrectas y cuenta inactiva.

## Cliente

1. Buscar y filtrar productos.
2. Agregar dos productos al carrito.
3. Abrir el carrito y verificar que no se cierre.
4. Cambiar cantidades y comprobar el límite de stock.
5. Crear un pedido para mesa.
6. Crear otro pedido para delivery.
7. Solicitar boleta.
8. Solicitar factura con RUC, razón social y dirección.
9. Cancelar un pedido no pagado y comprobar la devolución de stock.
10. Consultar el comprobante después de que recepción registre el pago.

## Recepcionista

1. Abrir el dashboard.
2. Registrar una venta directa para Cliente Mostrador.
3. Cobrar y emitir boleta.
4. Registrar otra venta con factura.
5. Crear y editar productos.
6. Asignar una imagen por galería y otra por cámara.
7. Procesar un pedido: confirmar, preparar y dejar listo.
8. Registrar el pago.
9. Marcar el pedido como entregado.
10. Abrir y compartir el PDF del comprobante.

## Administrador

1. Revisar el dashboard general.
2. Crear un recepcionista.
3. Crear otro administrador.
4. Editar y desactivar un usuario.
5. Verificar que no pueda desactivar su propia cuenta.
6. Gestionar inventario.
7. Registrar una venta de caja.
8. Filtrar pedidos, usuarios y comprobantes.

## Persistencia

1. Agregar productos al carrito y cerrar la app.
2. Abrir nuevamente y comprobar el carrito.
3. Crear un pedido y reiniciar la app.
4. Comprobar historial, stock y comprobantes.

## Sin internet

1. Desactivar internet.
2. Abrir Inicio; puede mostrarse un aviso por recetas remotas.
3. Verificar que autenticación local, carta, carrito, pedidos, administración y comprobantes sigan operativos.
